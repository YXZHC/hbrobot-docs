# 维护与安全

WS2024-Lyon Agri-AMR 的日常维护不复杂，关键是形成固定检查习惯。建议把本页的检查项做成点检表，按班次或按周执行。

## 每次使用前

- [ ] 急停按钮可以按下并正常复位。
- [ ] 电池电量充足，插头无松动、无烧蚀痕迹。
- [ ] 轮胎无破损、无缠绕异物。
- [ ] 激光雷达视窗干净，无遮挡。
- [ ] 行驶区域无积水、无散落线缆。
- [ ] 机器人上方和周围没有易坠落物品。

## 每周检查

- [ ] 清洁底盘表面与传感器视窗。
- [ ] 检查轮组螺丝与货架/外设固定件是否松动。
- [ ] 检查线缆有无磨损、折弯或靠近运动部件。
- [ ] 测试急停、防撞和避障功能。
- [ ] 观察直线行驶是否明显跑偏。

## 每月检查

- [ ] 检查电池外观有无鼓包、渗液或异味。
- [ ] 检查充电器与充电接口是否过热。
- [ ] 校准或复核 IMU、轮径与角速度系数。
- [ ] 检查软件版本与日志中的重复告警。
- [ ] 清理主控与驱动器散热区域的灰尘。

## 电池使用与保养

| 项目 | 建议 |
| --- | --- |
| 充电时机 | 电量低于 20%–30% 时及时充电，避免深度放电 |
| 存放电量 | 长期存放保持在 40%–60% |
| 存放环境 | 阴凉、干燥、远离可燃物 |
| 充电环境 | 通风良好，周围不要堆放杂物 |
| 异常处理 | 发现鼓包、异味、异常发热立即停止使用 |

:::danger 电池安全
不要拆解、挤压、短路电池，也不要在高温或潮湿环境中充电。电池出现鼓包或渗液时，请隔离并联系专业人员处理。
:::

## 清洁

1. 先关机并断开电池。
2. 用干燥或微湿的无绒布擦拭外壳。
3. 激光雷达视窗用镜头布轻轻擦拭，不要使用腐蚀性清洁剂。
4. 不要用高压水枪冲洗，不要让液体进入接口和散热孔。

## 软件与固件更新

更新前请：

1. 备份当前参数与地图。
2. 确认电池电量高于 50%。
3. 阅读更新说明，确认是否需要重新标定。
4. 更新后先空载低速测试，再恢复正式任务。

## 安全操作规范

- 调试时保持一只手可触及急停。
- 不要站在机器人正前方或轮组附近。
- 不要让机器人在无人看管的情况下运行。
- 不要超过额定负载或擅自改装电气回路。
- 发生异响、冒烟、焦味时，立即断电并隔离。

## 长期存放

1. 清洁整机并充满至 50% 左右。
2. 断开电池，放在干燥阴凉处。
3. 每月检查一次电池电量，必要时补电。
4. 重新启用前执行一次完整点检和低速测试。
