## 这台机器人适合做什么

**WS2024-Lyon Agri-AMR**（中文名：**WS2024 里昂农业自主移动机器人**）是面向农业场景的自主移动机器人平台。整机以 ROS 2 为软件底座，围绕底盘运动、激光雷达、IMU、执行机构与视觉应用组织文档，适合课程教学、算法验证、农业场景联调和二次开发。

- **教学实训**：从 ROS 2 通信、Python 编程到移动机器人综合任务，按章节循序渐进。
- **农业场景验证**：围绕田间/温室巡检、物料转运与传感器采集，验证定位、规划和控制策略。
- **硬件与标定**：提供 VMX-Pi、TiTan 驱动器、底盘运动学、激光雷达、IMU 与 Wi-Fi 的参数说明。
- **二次开发**：开放底盘、执行机构与传感器接口，配套可复用的 Python 与 ROS 2 示例。

## 建议的学习顺序

1. **先认识整机**：阅读本页和[规格参数](/amr-a/specs)，确认能力边界与安全注意事项。
2. **跑通第一次**：按[快速开始](/amr-a/quick-start)完成开箱、上电、联网和遥控。
3. **搭好开发环境**：参考[开发环境配置](/docs/software/preparation)准备 Ubuntu、ROS 2 与常用工具。
4. **补齐基础知识**：按需学习 [ROS 2](/docs/basics/ros2/ros2-overview) 与 [Python](/docs/basics/python/python-overview)。
5. **进入控制与应用**：从[底盘速度控制](/amr-a/applications/chassis-control/basic-velocity-control)开始，逐步进入导航、视觉与综合任务。
