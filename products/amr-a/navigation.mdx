# 导航与调参

本页给出 WS2024-Lyon Agri-AMR 从建图到 Nav2 导航的推荐流程，以及轻巧型底盘常用的参数调整方向。具体数值需要在你的场地、负载和传感器配置下实测确定。

## 整体流程

```mermaid
flowchart LR
    A[检查传感器] --> B[建图]
    B --> C[保存地图]
    C --> D[AMCL 定位]
    D --> E[代价地图]
    E --> F[路径规划]
    F --> G[速度控制]
    G --> H[现场验证]
```

## 1. 导航前的检查

- 激光雷达 `/scan` 数据正常，方向与安装位置一致。
- TF 树完整，`map → odom → base_link → laser` 可以正常查询。
- 里程计方向正确：前进时 `odom` 的 x 增大，左转时 yaw 增大。
- IMU 已标定，角速度无明显漂移。
- 急停、防撞条和避障区域已确认有效。

:::tip 先验证里程计
导航跑偏很大一部分原因不在 Nav2，而在里程计。先让机器人直线走 1 m、原地转 360°，确认实际距离和角度与里程计一致，再开始调 Nav2。
:::

## 2. 建图

```bash
# 以实际镜像中的建图包名为准
ros2 launch amr_slam slam.launch.py
ros2 launch amr_bringup bringup.launch.py
```

用键盘遥控低速走完整个区域，尽量形成闭环。保存地图：

```bash
ros2 run nav2_map_server map_saver_cli -f ~/maps/amr_a_map
```

建图时注意：

- 速度放慢，避免激光雷达运动畸变。
- 每个角落都要扫描到，门框和玻璃附近多走几遍。
- 地图保存后检查分辨率、原点和障碍物边缘是否清晰。

## 3. AMCL 定位

启动导航后，在 RViz 中使用 **2D Pose Estimate** 给出初始位姿。定位稳定的标志：

- 激光点云与地图墙体重合。
- 机器人移动时粒子云收敛，不大范围跳动。
- `map → odom` 变换连续，无明显跳变。

如果定位频繁丢失，优先检查：

1. 初始位姿是否给得偏离太远。
2. 地图是否与当前场地一致。
3. 激光雷达安装位置与 `laser_frame` 是否匹配。
4. 场地是否有大面积玻璃、长走廊或动态人群。

## 4. 关键参数建议

以下参数位于 Nav2 的 `nav2_params.yaml` 中。WS2024-Lyon Agri-AMR 车身较小，可以适当收紧膨胀层，但不要贴墙太近。

| 参数 | 建议起点 | 调整方向 |
| --- | --- | --- |
| `robot_radius` | 按实测外接圆填写 | 宁大勿小，需覆盖最大外设 |
| `inflation_radius` | `robot_radius + 0.25` | 太小易擦墙，太大会堵住窄通道 |
| `cost_scaling_factor` | 3.0 | 增大让机器人更愿意远离障碍 |
| `max_vel_x` | 0.35 m/s | 教学与巡检场景先求稳 |
| `max_vel_theta` | 1.0 rad/s | 转向不稳时降低 |
| `acc_lim_x` | 0.8 m/s² | 启停抖动时降低 |
| `acc_lim_theta` | 1.5 rad/s² | |
| `xy_goal_tolerance` | 0.10 m | 对接工位时按需收紧 |
| `yaw_goal_tolerance` | 0.15 rad | |
| `controller_frequency` | 20 Hz | 算力不足时降低 |

:::warning 一次只改一类参数
同时改速度、加速度和膨胀层，会让问题难以定位。建议按“定位 → 全局规划 → 局部控制 → 速度限制”的顺序逐项调整。
:::

## 5. 常见现象与处理

| 现象 | 优先检查 | 处理建议 |
| --- | --- | --- |
| 机器人贴墙走 | 膨胀层、代价地图 | 增大 `inflation_radius` 或 `cost_scaling_factor` |
| 窄通道过不去 | 机器人半径、膨胀层 | 确认 `robot_radius` 未包含不存在的虚影 |
| 原地反复转向 | 局部控制器、定位 | 降低角速度，检查 AMCL 是否稳定 |
| 到达目标附近停不下 | 容差、减速参数 | 调整 `xy_goal_tolerance` 与减速距离 |
| 走直线画龙 | 里程计、轮径 | 重新标定轮径与角速度系数 |
| 人一多就停 | 障碍层、动态障碍 | 调整障碍物衰减时间与避障策略 |

## 6. 现场验收

- 从地图任意位置设置目标点，连续执行 10 次，成功率达到预期。
- 窄通道、门口、充电桩附近分别测试。
- 人为放置低矮障碍物，确认避障或停车有效。
- 急停按下后，导航任务立即停止。
