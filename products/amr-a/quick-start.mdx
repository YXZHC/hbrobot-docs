# 快速开始

本页带你在最短时间内完成 WS2024-Lyon Agri-AMR 的开箱核对、上电、网络连接和第一次运动。全程约 20 分钟。

:::info 开始之前
请在平整、开阔、周围 1 m 内无障碍的场地上操作；确认急停按钮可以正常按下并复位。首次上电时不要安装额外负载或外设。
:::

## 1. 开箱核对

对照装箱单检查以下物品。不同批次配置可能略有差异，以实际装箱单为准。

| 类别 | 物品 | 数量 | 备注 |
| --- | --- | :---: | --- |
| 主体 | 机器人底盘 | 1 | 含主控、电机、传感器 |
| 电源 | 电池组与充电器 | 1 | 首次使用前建议充满 |
| 网络 | 网线 | 1 | 有线调试用 |
| 工具 | 内六角扳手 | 1 套 | 日常维护 |
| 文档 | 快速入门卡 | 1 | 电子版见本站 |

检查外观是否有运输造成的磕碰、变形或线缆松脱。如有异常，先停止上电并联系售后。

## 2. 上电与自检

1. 将电池组推入电池仓，确认插头锁紧。
2. 释放急停按钮，把总电源开关拨到 **I**。
3. 观察面板指示灯：电源灯常亮，主控状态灯开始闪烁。
4. 等待 30–60 秒，让主控完成 Linux 与 ROS 2 启动。

:::warning 异常处理
如果上电后闻到焦味、听到明显异响，或指示灯全部熄灭，请立即断开总电源并停止使用。
:::

## 3. 连接机器人

WS2024-Lyon Agri-AMR 支持有线与无线两种调试方式。

### 有线连接

1. 用网线连接机器人的调试网口与电脑。
2. 将电脑有线网卡设置为与机器人同一网段，例如 `192.168.123.100/24`。
3. 执行 `ping 192.168.123.3`，确认网络连通。

### 无线连接

1. 在电脑的 Wi-Fi 列表中连接机器人热点（SSID 以机身标签为准）。
2. 默认密码见机身标签或随箱说明。
3. 连接后通过 SSH 登录：`ssh vmx@192.168.123.3`。

:::tip 网络排查
如果无法连接，先确认机器人已启动完成、电脑没有切换到其他网络，并检查 IP 是否在同一网段。详细步骤见[连接到机器人](/amr-a/quick-start/connect-to-robot)。
:::

## 4. 第一次运动

在机器人上打开终端，加载环境并启动底盘：

```bash
source /opt/ros/humble/setup.bash
source ~/robot_ws/install/setup.bash

# 包名以实际镜像为准
ros2 launch amr_bringup bringup.launch.py
```

另开一个终端，启动键盘遥控：

```bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

按 `i` 前进、`,` 后退、`j` / `l` 转向、`k` 停止。第一次测试时把速度调低，并保持一只手在急停按钮附近。

## 5. 确认结果

- 机器人能响应前进、后退与转向指令。
- `ros2 topic hz /odom` 能持续输出里程计数据。
- 急停按下后，底盘立即停止动力输出。
